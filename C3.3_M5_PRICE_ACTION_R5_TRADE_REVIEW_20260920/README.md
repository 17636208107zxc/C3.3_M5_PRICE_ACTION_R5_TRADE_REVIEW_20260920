# C3.3 R5 99笔虚拟交易质量复盘

本目录位于R5交付目录之外。复盘只读取R5既有源码、日志、候选、账本和同一MT5测试器行情，没有修改EA源码、RR参数或正式下单逻辑。

## 先看这里

- `04_REPORT/R5_99交易质量复盘.html`：浏览器直接打开的主报告，含99笔筛选表、20笔详细图文和7个重点案例。
- `04_REPORT/普通人中文总结.md`：简明结论和目前仍需人工选择的事项。
- `02_TRADE_INDEX/R5_99交易复盘索引.csv`：99笔完整索引。
- `02_TRADE_INDEX/frozen_20_sample.csv`：在人工图表结论前按固定分层及客观边界指标冻结的20笔样本。

## 明细

- `03_CHARTS/TRADES`：20张真实M5/M15交易图。
- `03_CHARTS/FOCUS`：第3、5、7、8、9、10、12笔重点行情图。
- `05_DETAILS/五条人工规则逐笔机械证据.csv`：五条规则中可由程序验证的部分。
- `05_DETAILS/R5规则执行待人工核对证据.csv`：程序不能替代人工判断的位置。
- `05_DETAILS/R5规则执行差异结论.csv`：已确认事实、待人工判断和计划核对项的汇总。
- `05_DETAILS/MFE_MAE与目标退出分析.csv`：逐笔退出结果。
- `05_DETAILS/实际TP距离分档统计.csv`：实际TP距离分档。
- `05_DETAILS/Route_ABCD独立账本统计.csv`：R5原有四条Route独立成绩。
- `05_DETAILS/99笔组合按Route方向统计.csv`：99笔去重组合内的Route与方向统计。
- `05_DETAILS/99笔账本逐笔核对.csv`：无重复、无遗漏的逐笔证据。

## 数据与验证

- `01_BROKER_DATA/TESTER_EXPORT`：从R5相同便携式MT5测试器导出的真实M5/M15 OHLC。
- `01_BROKER_DATA/tester_export_provenance.json`：经纪商、服务器、终端、文件哈希和行情交叉验证。
- `06_PACKAGE/review_validation.json`：完整性、因果、行情、图片和R5原文件未改动检查。

## 口径限制

- 佣金为0，额外滑点为0；净盈亏不能直接当作真实账户收益。
- 20笔详细案例的人工最终判断栏保持空白，等待人工逐笔选择。
- 第3、第8、第9笔仍保留原始事实：人工关注位置没有形成2R合格交易。
